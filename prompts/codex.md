# Second Wind for Codex (and other AGENTS.md agents)

Copy the file `prompts/AGENTS.md` into the root of your project (or paste its contents into an existing `AGENTS.md`). For all projects, put it in `~/.codex/AGENTS.md`. Works with OpenAI Codex CLI, and any agent that reads AGENTS.md (Cursor, Jules, Aider, Gemini CLI via GEMINI.md, and others). Then type `/secondwind` or "second wind" in the chat.
