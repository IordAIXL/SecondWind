# Second Wind browser extension

Adds a little can button next to the chat box on ChatGPT, Claude, Gemini, Grok, Copilot, Perplexity, DeepSeek, Mistral, Meta AI, Poe and Google AI Studio. Click it, pick a brand and flavor, and a "here's a drink" message (with the "dialed in" focus block) goes into the chat box. Works with no setup on the AI's side.

`manifest.json`, `data.js`, `cans/` and `icons/` are generated by `python3 tools/build_extension.py` (which `tools/build.py` runs for you). Edit `content.js`, `popup.html` and `popup.js` by hand.

The download is `docs/downloads/second-wind-extension.zip`.

## Install (Chrome, Edge, Brave, Opera)

1. Download and unzip `second-wind-extension.zip`.
2. Open `chrome://extensions` (or `edge://extensions`).
3. Turn on **Developer mode**.
4. Click **Load unpacked** and pick the unzipped `second-wind` folder.

## Install (Firefox)

1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on** and pick `manifest.json` inside the unzipped folder.

Firefox removes temporary add-ons when it closes. A permanent Firefox install needs the add-on signed by Mozilla.
