# Fonts for the can art

These fonts are from Google Fonts and are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows using and redistributing them.
`tools/cans.py` turns the lettering into vector outlines, so the published cans don't need the fonts installed.

Anton, Archivo Black, Inter, DM Serif Display, Pacifico, Saira Condensed, Rubik, Russo One, Oswald.
